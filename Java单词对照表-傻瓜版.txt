========================================================
        Java 单词对照表（傻瓜版）
        鲸鱼娘出品 · 用法：不懂哪个词，就翻到它
========================================================

  怎么看这张表？
  每个词分四行：英文原意 → 人话 → 类比 → 例子
  看不懂某个词，就只翻那一个，不用从头读。


========================================================
  第一部分：骨架词（几乎每段代码都能看到）
========================================================

----- public -----
英文原意：公开的
人话：先照写，现在别管它（以后学"类与对象"才懂它的真正用处）
例子：public class Temperature

----- class -----
英文原意：种类、班级
人话：一张"图纸"。你的代码都住在某张图纸里
类比：电机型号图纸（先有图纸，才能造实物）
例子：public class Sensor { ... }
注意：文件名要和 class 后面的名字一模一样！（Sensor.java 配 public class Sensor）

----- static -----
英文原意：静止的
人话：不用先"造实物"，直接就能用
类比：挂在车间墙上的公共工具——谁都能直接拿去用
      （反过来说：没写 static 的，就像每个人自己兜里的工具，得先有"人"（对象）才能用）
例子1：static double round1(double x)  →  直接喊 round1(3.14) 就能用
例子2：void read(double t)             →  没 static，必须先 new 出对象，再 s1.read(35.8)

⚠️ 报错长相（在 static 方法里不点名就用非 static 的东西时）：
   non-static variable mine cannot be referenced from a static context
   non-static method read() cannot be referenced from a static context
   翻译："在静态地盘（比如 main）上，你不点名就想用私人物品——不行！"
   解决：通过对象点名 → a.mine / a.read(...)
   注意：这是"编译期"就报错（代码还没跑就被拦），属于最好抓的错误

----- void -----
英文原意：空的、无效的
人话：这个方法"只干活，不往回带东西"
类比：去食堂打饭——干完活，不给你餐盘带回来
反面：double round1(double x) → 干完活，端回来一个数字
例子：void read(double t) { ... }   ← 方法里没有 return，因为不往回带东西

----- return -----
英文原意：返回
人话：把结果"递回去"
类比：子程序把算出来的值交还给调用者
例子：return Math.round(x * 10) / 10.0;   ← 把算好的数递出去

----- main -----
英文原意：主要的
人话：程序的"入口"，Java 从这个方法开始跑
类比：上电启动按钮
例子：public static void main(String[] args) { ... }
记住：每个程序只有这一个入口（一个类里只能有一个 main）

----- new -----
英文原意：新的
人话：按"图纸"造一个"实物"出来
类比：照图纸造一台电机
例子：Sensor s1 = new Sensor();   ← 造一台传感器，名字叫 s1

----- String[] args -----
英文原意：string=文字串，args=arguments 参数
人话：main 的"小尾巴"，现在完全不用管它，照抄就行
例子：public static void main(String[] args)


========================================================
  第二部分：类型词（决定"装什么东西"）
========================================================

----- int -----
英文原意：integer 整数
人话：只能装整数（不能带小数点）
例子：int hour = 14;
类比：PLC 里的 INT 变量

----- double -----
英文原意：双倍精度
人话：能装小数（带小数点的数）
例子：double temperature = 35.8;
类比：PLC 里的 REAL 变量

----- boolean -----
英文原意：布尔的（人名）
人话：只能装"真"或"假"两个值
例子：boolean isOverheat = true;
类比：开关的"通/断"两个状态

----- String -----
英文原意：字符串
人话：装一串文字（要用双引号包起来）
例子：String name = "客厅传感器";

----- char -----
英文原意：character 字符
人话：装单个字符（用单引号）
例子：char grade = 'A';

----- double[] -----
英文原意：[] 是"数组"记号
人话：一格一格的抽屉，一排装很多小数
例子：double[] temps = {26.5, 27.0, 25.8};
读法：temps[0] 是第 1 格（从 0 数起！），temps.length 是总共几格

----- List<String> -----
英文原意：list 清单
人话：一个"清单"，装着好几行文字
例子：List<String> lines = Files.readAllLines(...);
读法：lines.get(0) 取第 1 行，lines.size() 是总行数


========================================================
  第三部分：判断和循环（控制程序怎么走）
========================================================

----- if -----
英文原意：如果
人话：条件成立就做某事
例子：if (temps[i] > 33.0) { 报警 }

----- else -----
英文原意：否则
人话：上一个 if 不成立时，做另一件事
例子：if (温度 > 33) { 报警 } else { 正常 }

----- for -----
英文原意：为了
人话：重复干 N 遍（最常用的循环）
例子：for (int i = 0; i < 24; i++) { ... }
逐字读："创造一个整数 i 从 0 开始；只要 i 小于 24 就继续；每圈结束 i 加 1"

----- while -----
英文原意：当……的时候
人话：只要条件成立就一直转
例子：while (i < 24) { ... }

----- i++ -----
英文原意：加加
人话：i 自己 +1（每转一圈就加一）
对比：i-- 是减一

----- >  <  >=  <= -----
人话：大于、小于、大于等于、小于等于
例子：temps[i] > 33.0

----- == -----
人话：判断"相等"（注意是两个等号！）
⚠️ 坑：一个等号 = 是"赋值"（把右边的值装进左边）
     两个等号 == 才是"比较"
例子：if (hour == 14) { 下午两点 }


========================================================
  第四部分：屏幕输出（打印字）
========================================================

----- System.out.println -----
英文原意：system=系统，out=输出，println=打印一行
人话：在屏幕上打印一行字（打完自动换行）
例子：System.out.println("你好");
逐字读："系统的输出口 打印一行"

----- System.out.print -----
人话：同上，但打完不换行

----- +（在打印里）-----
人话：如果两边有文字，它是"拼接"（把内容串起来），不是加法！
例子："温度: " + 35.8   →   温度: 35.8

----- String.format -----
英文原意：format=格式化（排版）
人话：把数字"打扮"成好看的格式
例子：String.format("%.1f", 3.14159)   →   "3.1"

----- %.1f -----
人话：塞一个小数进来，只留 1 位小数
表哥：%.2f 留 2 位；%d 塞整数；%s 塞文字
例子：String.format("%.2f", 3.14159)  →  "3.14"
⚠️ 坑：%d 只能配整数，塞小数会报错


========================================================
  第五部分：文件相关（读外面的数据）
========================================================

----- import -----
英文原意：导入
人话：在文件最上面声明"我要用这个工具"，用了才不用写全名
例子：import java.nio.file.Files;

----- Files -----
人话：读文件的工具箱
例子：Files.readAllLines(路径)

----- Path -----
英文原意：路径
人话：指出文件在哪里
例子：Path.of("E:/桌面/JAVA喵/temperatures.txt")
⚠️ 提醒：路径里的斜杠用 /（正斜杠），不要用 \

----- readAllLines -----
人话：一次把文件所有行读进来，变成一个清单
例子：List<String> lines = Files.readAllLines(...);

----- IOException -----
英文原意：input/output 输入输出异常
人话：读文件"可能失败"（文件不在、被占用……），Java 要求你必须处理这个可能性
例子：import java.io.IOException;

----- throws -----
英文原意：抛出
人话：我不处理，出事往上抛（新手最简做法）
例子：public static void main(String[] args) throws IOException

----- .get(i) -----
人话：从清单里取第 i 个（从 0 数起）
例子：lines.get(0)  取第 1 行

----- .size() -----
人话：清单里一共几条
例子：lines.size()  行数

----- Double.parseDouble -----
英文原意：parse=解析（翻译）
人话：把"文字"翻译成"数字"
例子：Double.parseDouble("26.5")   →   26.5（真的数字了）

----- .trim() -----
英文原意：修剪
人话：去掉文字两头的空格
例子：lines.get(i).trim()


========================================================
  第六部分：方法（一段能干活的代码块）
========================================================

  一个方法要交代四件事：

  1. 吐出什么？   → 返回类型（double = 吐小数，void = 不吐）
  2. 叫什么名字？ → 方法名（round1、read）
  3. 吃什么？     → 参数（写在括号里：(double x)）
  4. 干什么？     → 方法体（大括号里的代码）

  例子：
      static double round1(double x) {
          return Math.round(x * 10) / 10.0;
      }
  逐字读："静态的(不用造实物)、吐小数的方法、叫 round1、吃一个小数 x；
          干活内容：把 x 乘 10 四舍五入 再除以 10.0，然后吐出去"

  调用（用一次）：round1(3.14159)   →  结果 3.1


========================================================
  第七部分：自定义名字常用词（这些不是关键字，是人起的名字）
========================================================

  ★ 先记住一条：Java 的词分两种
    ① 关键字（字典词）：class / public / static / void / double / if / for……
       —— 必须照写，改一个字母就报错（本表前面六部分都是这类）
    ② 自定义名字：类名 / 变量名 / 方法名，由写代码的人自己起
       —— 表里查不到很正常！判断口诀："这个词我能随便改吗？能改 = 自定义名"

  ★ 起名用英文单词，所以"看懂英文" = 看懂别人的代码
     拆分例子：isOverheat = is（是否）+ over（超过）+ heat（热）→ 是否过热
               readTemperature = read（读）+ Temperature（温度）→ 读温度

  ------ 你已经在用的自定义名字 ------
  Sensor        传感器（你起的类名）
  Device        设备
  Motor         电机
  name          名字
  temperature   温度
  read          读（读取数据）
  isOverheat    是否过热
  start / stop  启动 / 停止
  s1 / s2       传感器1 / 传感器2（s 是 sensor 的缩写）
  sensors       传感器们（复数 = 一堆）
  round1        圆整到 1 位
  temps         温度们（temperatures 的缩写）
  maxtemp       最高温（max = 最大）
  mintemp       最低温（min = 最小）
  avg           平均值（average 缩写）
  sum           总和
  count         计数 / 数量

  ------ 以后起名常用的英文（比背关键字更实用）------
  【动作类】
  get         获取（取值）
  set         设置（赋值）
  read/write  读 / 写
  add         添加
  remove      移除
  create      创建
  delete      删除
  update      更新
  check       检查
  open/close  开 / 关
  send        发送
  receive     接收
  calculate   计算

  【数量/状态类】
  max / min   最大 / 最小
  total       总计
  count       数量
  size        大小（个数）
  length      长度（⚠️ 注意拼写：l-e-n-g-t-h，你踩过这个坑）
  index       下标（第几个）
  value       值
  is / has    是否 / 有（常用于判断：isReady、hasPower）
  enable/disable  启用 / 禁用
  status      状态

  【你专业的词（以后写工控程序天天用）】
  power       电源 / 功率
  voltage     电压
  current     电流（⚠️ 也有"当前"的意思）
  resistance  电阻
  frequency   频率
  motor       电机
  sensor      传感器
  switch      开关
  relay       继电器
  breaker     断路器
  panel       面板 / 配电盘
  meter       仪表 / 电表
  fault       故障
  alarm       报警
  monitor     监测
  control     控制
  system      系统
  device      设备
  signal      信号
  data        数据

  ------ 起名三条规则 ------
  1. 只能用字母、数字、下划线，且不能以数字开头
  2. 不能跟关键字撞名（不能叫 class、void、double）
  3. 见名知意 + 驼峰写法：小写开头，后面每个单词首字母大写
     例：maxTemperature（最高温）、isOverheat（是否过热）、readValue（读值）
