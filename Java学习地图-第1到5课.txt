========================================================
  第 1 课：程序长什么样
========================================================
  public class 类名 {                      ← 文件必须叫「类名.java」
      public static void main(String[] args) {   ← 程序入口，从这里开始跑
          System.out.println("你好");            ← 打印一行
      }
  }

  ★ 核心：main 是唯一会自动执行的方法；其他方法必须"被调用"才跑
  ★ 坑：分号、大括号配对、文件名要和 public 类名一模一样


========================================================
  第 2 课：数据与逻辑
========================================================
  【变量】 类型 名字 = 值;
      int      整数
      double   小数
      boolean  真/假（true / false）
      String   文字（双引号）

  【数组】 double[] temps = {26.5, 27.0};
      temps[0]        第一格（从 0 开始数！）
      temps.length    一共几格

  【循环】 for (int i = 0; i < temps.length; i++) { ... }
      i 从 0 开始；i < 长度 才继续；每圈 i 加 1

  【判断】 if (条件) { ... } else { ... }
      == 是"比较相等"（两个等号）；= 是"赋值"（一个）

  【累加】 sum = sum + temps[i];      （sum 从 0 开始！）

  【格式化】 String.format("%.1f", x) → "3.1"
      %.2f 两位小数 / %d 整数 / %s 文字

  ★ 坑：数组越界、循环条件写反（i < 不是 >）、整数除法（要写 10.0）


========================================================
  第 3 课：方法（一段能干活、可能有产出的代码块）
========================================================
  定义四件套：
      static  double  round1 (double x) { return ...; }
        ↑      ↑        ↑       ↑
        |   返回类型    名字    参数（吃什么）
     "公共工具"字样

  【两类方法】
      有 static   → 公共工具，直接喊：round1(3.14)
      没有 static → 实物的技能，必须点名：s1.read(35.8)

  【返回类型 vs void】
      要"拿结果去用"  → 写具体类型（double / boolean / int…）
      只是"让它干件事" → void（不往回带东西）

  ★ 坑：在 static 环境（main）里"不点名"就用非 static 的东西
         → 报错 non-static ... cannot be referenced from a static context


========================================================
  第 4 课：类与对象
========================================================
  类   = 图纸（规格说明）      对象 = 按图纸造出的实物
  new 三步： ① 申请空间 → ② 按图纸造（字段就位）→ ③ 交给变量

  【字段】= 属性（name、temperature）——每个对象各一份
  【方法】= 功能（read()、isOverheat()）
  【使用】点号： s1.name、s1.read(35.8)

  【数组装对象】
      Sensor[] sensors = new Sensor[3];   ← 搭 3 个空槽位
      for (int i = 0; i < sensors.length; i++) {
          sensors[i] = new Sensor();      ← ⚠️ 每格都要 new！
      }

  【作用域】变量只活在自己出生的那对 {} 里

  ★ 坑：忘了 new（空槽位报错）、把 main 里的变量拿到 main 外面用


========================================================
  第 5 课：继承
========================================================
  class 子类 extends 父类 { ... }        ← extends = 继承

  【好处】父类的字段/方法，子类自动拥有（不用重抄）
      ① 避免重复  ② 改一处全生效  ③ 少出错
  【规矩】一个类只能继承一个父类；一个文件只能有一个 public 类
  【MC 例子】Block → CraftingTableBlock ；Entity → Zombie ；Item → 各种装备

  ★ 坑：方法名抄错（start/stop）、子类里重复定义父类已有的东西

========================================================
  你踩过的坑（"坑册"——踩过的都记着，别再踩）
========================================================
   1. 记事本偷偷加 .txt（保存代码要选"所有文件"）
   2. cd 跨盘符要加 /d
   3. 语句末尾漏分号
   4. 大括号多一个/少一个（代码"掉出"方法外）
   5. 名字拼写前后不一致（maxtemp/maxTemp、temperature/temperture）
   6. 循环条件写反（i > length → 循环一次都不跑，还不报错！）
   7. 整数除法（/10 应为 /10.0）
   8. 在 main 里不点名就用非 static 的东西
   9. "找不到 main" → 检查：main 在 public 类里？拼写？static？String[] args？
  10. 方法名/英文单词抄错（start/stop、leagth/length、Mater/Meter）
