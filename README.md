## ⭐ 项目：SensorMonitor（传感器监控系统）

模拟工业传感器监控的命令行工具，从 v1.0 迭代到 v1.6。

**功能**

1. 读取传感器数据文件（支持脏数据：空格 / 空行 / 格式错误都会被跳过）
2. 按类型创建对应对象（温度 / 电压 / 湿度）
3. 多态统一处理：启动 → 采集 → 超限判断 → 报警 → 停止
4. 报表按数值降序输出 + 报警统计
5. 交互式查询：输入设备名即可查看状态

**版本演进**

| 版本 | 内容 |
|---|---|
| v1.0 | 继承 / 接口 / 多态 + 文件读取 + split |
| v1.1 | stop() / 报表统计 / 未知类型兜底 |
| v1.2 | Map 按名字查询 + null 检查 |
| v1.3 | Scanner 交互查询（while 循环） |
| v1.4 | 异常处理（文件 IO + 数据解析） |
| v1.5 | 数据清洗（trim + 空行跳过） |
| v1.6 | 排序：报表按数值降序（Lambda 比较器） |

**技术点**：面向对象（继承 / 重写 / 接口 / 多态）、集合（List / Map）、文件 IO、异常处理、字符串处理、排序、Scanner 交互

**运行方式**

```bash
javac -encoding UTF-8 SensorMonitor.java
java SensorMonitor
```

数据文件 `sensors.txt` 格式：

```
类型,名称,当前值,报警阈值
温度,客厅,35.8,33.0
温度,机房,26.1,33.0
电压,总闸,238.0,242.0
湿度,仓库,45.0,60.0
```
